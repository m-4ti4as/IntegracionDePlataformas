# Actas semanales

Guarda las actas semanales en Markdown con el nombre `Acta-AAAA-MM-DD.md`. Registra los participantes, los acuerdos y sus responsables. Vincula cada compromiso al archivo, incidencia o commit correspondiente cuando exista.

## Plantilla de reunión

- **Fecha y modalidad** [completar]
- **Participantes** [nombres y apellidos]
- **Compromisos revisados** [compromiso anterior, responsable, estado y evidencia]
- **Decisiones y dificultades** [acuerdos y motivos]
- **Tareas acordadas** [tarea, responsable, fecha y resultado esperado]
- **Siguiente seguimiento** [completar]
